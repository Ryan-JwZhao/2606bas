# 独立几何校准工作台

## 简介

主界面的“校准工作台”是当前唯一推荐的相机—投影仪校准入口。旧的手工投影图案、外部脚本、手工加载结果和传统/工程模式切换已经从前端移除。

工作台包含完整图形化流程：

1. 启动或停止工业相机预览；
2. 查看相机方向、像素坐标域、联合校准和球心补偿状态；
3. 自动进行全域、中心和袋口 ChArUco 联合校准；
4. 自动进行30点球心补偿；
5. 选择独立 Holdout JSON 并在窗口中查看验收报告；
6. 将校准结果和残差直接显示到投影仪。

不需要执行任何命令。

## 未校准时如何开始

即使当前投影校准不存在、质量不合格或与当前投影校准方向不兼容，“启动相机预览”与“开始联合校准”仍保持可用。程序只暂停依赖毫米坐标的规划和投影几何，不会阻止相机采集、画面显示或像素域检测。

操作步骤：

1. 点击主界面左侧“校准工作台”。
2. 点击“启动相机预览”。
3. 在工作台预览区确认画面方向、曝光和焦点。
4. 如需调整，点击“打开采集与几何设置”。当前现场将“工业相机安装方向”设为 `180°`；校准与运行投影共用同一坐标系，投影仪小角度继续使用颗星公式细调。
5. 点击“开始联合校准”，按窗口提示保持设备和球桌不动。
6. 联合校准通过后，工作台会自动开放“开始球心补偿”“投影显示校准结果”和“开始图形化验收”。

联合校准会临时停止实时 pipeline 并独占相机。工作台会记住这次设备实际输出的旋转后分辨率；返回工作台后即使相机已停止，也会用该尺寸校验刚生成的文件。只要采集设备、请求分辨率、帧率、相机方向、视频源或畸变配置发生变化，记忆尺寸就自动失效，要求重新启动相机确认实际输出。

## 状态控制规则

- **未完成联合校准**：相机预览、设置、联合校准可用；规则模式和普通训练模式不会进入毫米坐标规划器，纯投影训练不受影响。
- **联合校准有效但球心补偿缺失**：开放球心补偿和投影结果检查。
- **检测模型未启用**：球心补偿保持禁用，并提示先启用球检测。
- **联合校准和球心补偿均有效**：推荐选择独立 Holdout 进行正式验收。
- **相机坐标域、分辨率、畸变或模型指纹变化**：相关产物显示“需重标定”，不会静默套用旧结果。旧版投影旋转仅作为升级兼容层存在，不进入新校准上下文。

## 前端已删除的旧功能

- 已停用的传统投影校准链路及其模式选择；
- 手工“显示 ChArUco 校正码”；
- 手工“显示编码网格”；
- 通过外部脚本生成投影 JSON 的操作说明；
- 手工应用、加载或另存联合校准文件；
- 依赖命令行查看状态或运行 Holdout 验收的流程。

联合校准和球心补偿仍会自动生成带时间戳的 JSON，并自动写回当前配置，用户不需要管理保存步骤。
