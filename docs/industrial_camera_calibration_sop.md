# BAS 工业相机校准操作步骤

本文只说明如何在 BAS 程序内部完成工业相机校准。整个过程使用图形界面操作，不需要运行命令，也不要手工修改校准文件。

## 一、校准前准备

开始前确认：

- 工业相机、投影仪和球桌已经固定好；
- 校准过程中不要移动相机、镜头、投影仪或球桌；
- 相机和投影仪建议开机预热 20 分钟；
- 镜头已经对焦，整个球桌画面清晰；
- 投影仪使用正式运行时的屏幕、分辨率和显示设置；
- 球桌表面干净，没有球杆、杂物或其他遮挡物；
- 准备一颗尺寸正确、表面干净的标准台球，后面做球心补偿时使用。

只要相机位置、镜头焦距、相机方向、相机分辨率、投影仪位置或投影分辨率发生变化，就要重新执行本文流程。

## 二、启动 BAS

双击项目根目录下的：

```text
Start_BAS.cmd
```

等待 BAS 主界面完全打开。

## 三、检查相机设置

### 1. 打开设置

在 BAS 主界面打开 **设置 → 相机采集**。

### 2. 选择工业相机

依次确认：

- 相机后端选择正确；
- 相机设备选择正确；
- 分辨率使用正式运行值；
- 帧率使用正式运行值；
- 工业相机安装方向正确。

当前现场如果相机画面与投影方向相差 180°，将 **工业相机安装方向** 设置为 **顺时针 180°**。

不要为了修正相机方向去旋转投影输出。相机方向只在 **工业相机安装方向** 中设置。

### 3. 调整画面

建议先关闭：

- 自动曝光；
- 自动白平衡。

然后手动调整曝光、白平衡和镜头焦点，直到：

- 整个球桌都能看清；
- 台边和袋口边缘清晰；
- 画面不过亮，也不过暗；
- 没有明显拖影、频闪或大面积反光；
- 画面中心和四角都清晰。

完成后保存设置。

## 四、启动相机预览

1. 返回 BAS 主界面。
2. 点击左侧 **校准工作台**。
3. 点击 **启动相机预览**。
4. 等待画面稳定。

在预览中检查：

- 相机方向是否正确；
- 整张球桌是否完整入镜；
- 六个袋口是否都能看见；
- 画面是否清晰；
- 曝光和白平衡是否稳定；
- 台面边界和已有标记是否与真实球桌一致。

如果不符合要求，点击 **打开采集与几何设置** 返回调整。调整后重新启动相机预览确认。

预览未通过时不要开始校准。

## 五、开始联合校准

### 1. 清空球桌

移走台面上的所有球、球杆和杂物，确保投影画面无遮挡。

### 2. 启动校准

1. 在 **校准工作台** 点击 **开始联合校准**。
2. 弹出“一键联动校正”窗口后，点击 **开始一键联动校正**。
3. BAS 会自动停止正在运行的实时采集，并独占相机进行校准，这是正常现象。
4. 等待程序自动完成全部校准画面的显示、识别和计算。

校准过程中：

- 不要移动任何设备；
- 不要触碰球桌；
- 不要调整曝光、焦点或白平衡；
- 不要修改 Windows 显示设置；
- 不要移动投影窗口；
- 不要在球桌上走动或制造明显阴影。

### 3. 观察校准过程

重点观察预览窗口和运行日志。

如果出现以下情况，应停止并重新开始：

- 投影画面显示不完整；
- 画面明显过曝或过暗；
- 投影内容模糊；
- 某个区域被遮挡；
- 程序连续提示识别失败；
- 相机或投影仪在过程中发生移动。

校准成功后，BAS 会自动保存结果并更新当前设置，不需要手工选择保存位置。

## 六、检查联合校准结果

1. 关闭联合校准窗口，返回 **校准工作台**。
2. 点击刷新校准状态。
3. 确认联合校准显示为有效状态。
4. 点击 **投影显示校准结果**。

重点检查以下位置：

- 球桌中心；
- 四个角；
- 两条长边中间；
- 两条短边中间；
- 六个袋口附近。

正常结果应满足：

- 投影方向正确，没有旋转、镜像或上下颠倒；
- 投影边界与真实台面边界基本重合；
- 中心和边缘都准确；
- 不存在“一边准确、另一边明显偏离”；
- 六个袋口附近没有明显单独偏移。

如果整体旋转或镜像，返回相机设置检查 **工业相机安装方向**，修正后重新执行联合校准。

如果中心准确但边缘偏移，先检查相机焦点、投影清晰度和设备是否松动，然后重新执行联合校准。

联合校准结果未通过人工检查时，不要继续球心补偿。

## 七、开始球心补偿

联合校准检查通过后，继续做球心补偿。

### 1. 准备标准球

1. 清空球桌，只保留一颗标准球。
2. 清洁球体，避免污渍和强反光影响识别。
3. 返回正常预览，确认 BAS 能稳定识别这颗球。

如果 **开始球心补偿** 按钮不可用，先检查：

- 联合校准是否有效；
- 球检测是否已经启用；
- 相机预览中是否能正常识别球。

### 2. 执行补偿

1. 在 **校准工作台** 点击 **开始球心补偿**。
2. 程序会依次在球桌上显示 30 个目标位置。
3. 每出现一个目标位置，就把标准球移动到目标位置。
4. 调整球的位置，使投影提示与球的位置尽量同心。
5. 完全松开球，等待球静止。
6. 不要用手扶球，等待程序完成倒计时并自动记录。
7. 记录成功后，再移动到下一个位置。

建议完成全部 30 个位置。不要只采集球桌中心，四边、四角和袋口附近的位置同样重要。

某个位置识别失败时：

1. 先确认球已经完全静止；
2. 擦掉球面污渍；
3. 避免手或身体产生阴影；
4. 选择重试；
5. 只有该位置确实无法识别时才跳过。

完成后返回校准工作台，刷新状态，确认球心补偿显示为有效。

## 八、进行图形化验收

如果现场已经准备了独立验收文件：

1. 在 **校准工作台** 找到 **独立 Holdout 验收**；
2. 点击选择文件；
3. 选择本次校准对应的验收文件；
4. 点击 **开始图形化验收**；
5. 查看程序显示的通过或失败结果。

验收文件必须是独立采集的数据，不能直接重复使用刚才校准和球心补偿的位置。

如果暂时没有验收文件，至少要进行一次现场人工检查：

1. 把标准球分别放到球桌中心、四角附近、四边中点和六个袋口附近；
2. 启动正常采集；
3. 检查 BAS 识别位置与实际球位置是否一致；
4. 显示投影路线或位置提示，检查落点是否准确；
5. 特别检查距离相机中心较远的区域。

## 九、校准完成后的最终检查

依次确认：

- [ ] 相机预览方向正确；
- [ ] 整个球桌和六个袋口完整可见；
- [ ] 曝光、白平衡和焦点稳定；
- [ ] 联合校准状态有效；
- [ ] 投影校准结果在中心、四边、四角和袋口附近均正常；
- [ ] 球检测稳定；
- [ ] 球心补偿状态有效；
- [ ] 正常运行时投影路线没有整体旋转或明显偏移；
- [ ] 关闭并重新启动 BAS 后，校准状态仍然有效；
- [ ] 相机、镜头和投影仪的固定位置没有变化。

全部通过后，才可以开始正式使用。

## 十、常见问题

### 1. 相机预览上下颠倒或旋转 180°

在 **设置 → 相机采集 → 工业相机安装方向** 中修正方向，然后重新完成联合校准和球心补偿。

### 2. 开始联合校准按钮可以点击，但校准失败

检查投影内容是否清晰完整、相机是否过曝、是否有遮挡、投影仪是否位于正确屏幕，以及设备是否发生移动。修正后从头重做。

### 3. 中心位置准确，边缘位置偏移

检查相机四角是否清晰、投影仪是否虚焦、Windows 显示缩放是否改变，以及相机或投影仪支架是否松动。处理后重新联合校准。

### 4. 某一个袋口附近偏移明显

检查该袋口是否有阴影、反光或遮挡，然后重新联合校准。不要只用手工偏移去掩盖局部问题。

### 5. 球心补偿按钮不可用

通常是联合校准无效、球检测未启用，或者当前检测模型无法稳定识别标准球。

### 6. 球心补偿时一直等待

确保球完全静止、手已经离开、球体轮廓清晰且没有强反光。必要时重新放球后点击重试。

### 7. 重启 BAS 后提示需要重新校准

说明相机设备、分辨率、方向、画面设置、投影设置或检测配置与校准时不一致。恢复原设置，或者重新完成全部校准。

## 十一、必须重新校准的情况

发生以下任一情况时，重新执行 **联合校准 → 结果检查 → 球心补偿 → 验收**：

- 相机、镜头、投影仪或球桌被移动；
- 相机安装方向改变；
- 相机分辨率或采集设备改变；
- 镜头焦距或对焦位置改变；
- 投影仪分辨率、屏幕编号或 Windows 显示设置改变；
- 投影仪位置、角度或焦点改变；
- 球桌边界设置或球尺寸设置改变；
- 球检测模型改变；
- BAS 明确提示当前校准结果不兼容。

不要通过手工修改校准文件来消除“不兼容”提示。
