# 工业相机—投影仪联合校准与球心补偿重标定手册

## 1. 适用范围

本流程适用于更换、移动或旋转工业相机之后，从零重新完成：

1. 相机画面方向归一化；
2. 可选的镜头畸变标定；
3. 相机像素、台面毫米坐标与投影仪像素的二维联合校准；
4. 标准台球的图像球心补偿；
5. 使用独立留出点验收。

系统不使用相机外参。几何模块内部保持三条独立关系：

```text
普通相机像素 <-> 台面毫米
台面毫米 <-> 投影仪像素
球图像中心   -> 真实球心的台面毫米
```

相机方向、采集分辨率、畸变坐标域、投影校准文件、检测模型或球直径改变后，旧校准文件会被判定为不兼容，避免静默使用错误坐标。

## 2. 开始前准备

- 固定相机、镜头、投影仪和球桌；校准完成前后都不要再移动。
- 投影仪和相机预热至少 20 分钟。
- 固定焦距、光圈、曝光、增益和白平衡，关闭自动曝光和自动白平衡。
- 投影仪使用实际运行分辨率和同一个 Windows 屏幕编号，不要在校准后缩放桌面。
- 清洁镜头与台面，避免强反光、球影和环境光变化。
- 准备标准直径球，默认配置为 `57.15 mm`。
- 准备 ChArUco 标定图案，并确保相机能清晰看见黑白边缘。

建议保留旧 JSON 作为归档，不要覆盖；新向导会使用时间戳生成新文件。工程平面校准文件和球体补偿文件必须是两个不同路径。

## 3. 第一步：确认新相机的 180° 方向

1. 启动 `Start_BAS.cmd`。
2. 打开“设置 -> 相机采集”。
3. 将“相机安装方向归一化”设为“顺时针 180°”。
4. 保存设置并重新启动采集。
5. 在预览中确认台面左上、右下、六个袋口和实物方向一致。

必须先旋转到标准视图，再做畸变校正、联合校准和球心补偿。不要通过修改投影坐标或在末端再次旋转结果来抵消相机方向。

## 4. 第二步：镜头畸变标定（推荐）

如果相机机身、镜头、焦距、分辨率或对焦位置发生变化，应重新生成相机畸变文件。

1. 保持第 3 步的 180° 方向设置。
2. 使用 ChArUco 板采集 25～40 张清晰图像。
3. 覆盖画面中心、四角和四条边；同时改变距离、平移和小角度俯仰。
4. 避免全部图像都处于同一平面位置，也不要使用运动模糊图。
5. 生成 OpenCV 相机标定 YAML 后，在“工业相机畸变矫正”中选择该文件并开启矫正。
6. 重启采集，确认直线靠近画面边缘时不再明显弯曲。

如果现场明确决定不做畸变矫正，可以关闭开关并直接用原始像素域校准；之后联合校准、球心补偿和运行阶段都必须保持关闭，不能混用。

## 5. 第三步：检查台面几何与运行配置

1. 确认台面宽、高和球直径与实物一致。
2. 检查 `outline`、`inline` 和 `pocket` 几何文件在 180° 归一化后的预览上正确覆盖台面。
3. 将投影模式切换为“工程模式”。
4. 设置工程平面校准输出路径和工程球体补偿输出路径，确认两者不同。
5. 确认投影分辨率、屏幕编号和全屏设置就是正式运行值。
6. 暂时清空球桌，移除所有球和遮挡物。

稠密台面轮廓会自动提取为有序透视四边形，不再退化为轴对齐包围盒。

## 6. 第四步：执行相机—投影仪联合校准

1. 打开校准工具，点击“一键联动校正”。
2. 点击“开始一键联动校正”。
3. 不要移动相机、投影仪或球桌；等待系统依次投射：
   - 全域 ChArUco；
   - 中心细化图案；
   - 六个袋口重点图案。
4. 观察预览。如果某一图案过曝、欠曝、失焦或被遮挡，停止流程，调整曝光或对焦后从头重做。
5. 系统会自动拟合并保存带时间戳的工程平面校准 JSON。

联合校准只有同时满足以下条件才会保存：

- 有效 RANSAC 内点率不低于 `80%`；
- RANSAC 内点重投影 P95 不大于 `3 px`；
- 留一图案交叉验证 P95 不大于 `5 px`；
- 全域和中心图案均有效；
- 至少 4 个不同袋口区域有效，推荐 6 个全部有效；
- 每个参与求解的图案至少匹配 6 个角点。

任一门槛不满足时，不要放宽阈值硬保存。优先排查曝光、投影焦点、环境光、图案裁切、桌面缩放和设备松动。

## 7. 第五步：先检查联合校准文件

关闭校准窗口后，在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -m bas inspect-calib
```

至少确认：

- `projection_valid` 为 `true`；
- `projection_compatibility_errors` 为空；
- `projection_calibration_context.frame_rotation_degrees` 为 `180`；
- `camera_coordinate_domain` 与当前畸变开关一致；
- `geometry_model.geometry_mode` 为 `independent_2d`；
- `geometry_model.camera_extrinsics_used` 为 `0`。

此时只做平面投影抽查：在中心、四角、长边中点和袋口附近显示标记，确认没有整体 180° 翻转，也没有某一侧明显漂移。不要用这些抽查位置作为最终 Holdout 数据。

## 8. 第六步：执行球心补偿采样

1. 保持联合校准后的所有设置不变。
2. 清空台面，只保留一颗尺寸正确、轮廓清晰的标准球。
3. 确认球检测后端已开启，并能稳定输出球轮廓。
4. 点击“工程球体补偿向导”，再点击“开始自动采样”。
5. 向导会依次显示 `6 × 5 = 30` 个目标椭圆。每次把球移动到目标位置，使投影环与球位置同心，然后完全松手。
6. 保持球静止。系统需要连续稳定观测，并额外倒计时 3 秒后才记录该点。
7. 某点超时时优先选择“重试”；只有该位置确实无法检测时才跳过。
8. 完成后确认向导生成新的、带时间戳的球体补偿 JSON，并自动写回当前设置。

球心补偿的硬性要求和质量策略：

- 至少 20 个有效点，推荐完成全部 30 点；
- 覆盖中心、四角、两条长边、两条短边和袋口附近安全区域；
- 单点至少由 5 帧稳定观测形成；
- 几何质量低于 `0.55` 的球心不采纳；
- 检测半径必须处于当前位置预期半径的 `0.65～1.35` 倍；
- 分割椭圆优先，外观椭圆次之，检测框中心会被显著降权；
- 模型在采样凸包外连续衰减回平面几何，不再在边界发生毫米级跳变。

再次运行 `inspect-calib`，确认：

- `ball_compensation_valid` 为 `true`；
- `ball_compensation_compatibility_errors` 为空；
- 球补偿上下文中的旋转、分辨率、畸变文件指纹、投影文件指纹和检测模型指纹均与当前设置一致。

## 9. 第七步：采集独立 Holdout 验收数据

Holdout 点不能与联合校准角点或 30 个球心拟合点重复。正式验收至少采集 24 个点、8 个有名称的区域，并包含至少 4 个不同袋口区域。

建议分两组采集：

### 9.1 平面联合映射点

记录独立标记的相机像素、投影仪像素和实测台面毫米坐标：

```json
{
  "camera_px": [812.4, 426.8],
  "projector_px": [615.2, 338.7],
  "world_mm": [1270.0, 635.0],
  "zone": "center"
}
```

### 9.2 球心点

把标准球放在独立测量的位置，只记录精修后的相机球心和实测台面球心；球样本不要同时填写 `projector_px`：

```json
{
  "camera_px": [956.3, 512.1],
  "world_mm": [1880.0, 930.0],
  "kind": "ball_center",
  "zone": "pocket_rb"
}
```

完整文件格式：

```json
{
  "samples": [
    {
      "camera_px": [812.4, 426.8],
      "projector_px": [615.2, 338.7],
      "world_mm": [1270.0, 635.0],
      "zone": "center"
    },
    {
      "camera_px": [956.3, 512.1],
      "world_mm": [1880.0, 930.0],
      "kind": "ball_center",
      "zone": "pocket_rb"
    }
  ]
}
```

区域名建议固定为 `center`、`edge_top`、`edge_bottom`、`edge_left`、`edge_right`、`pocket_lt`、`pocket_rt`、`pocket_lb`、`pocket_rb` 等。

## 10. 第八步：运行正式验收

```powershell
.\.venv\Scripts\python.exe -m bas verify-calib C:\path\to\holdout.json
```

正式通过条件为：

- 独立样本不少于 24 个；
- 有名称区域不少于 8 个；
- 袋口区域不少于 4 个；
- 图像误差 mean `< 0.20 px`、P95 `< 0.35 px`；
- 台面误差 median `< 1.0 mm`、P95 `< 2.0 mm`；
- 各袋口区域 P95 `< 2.5 mm`；
- 误差随距离的斜率绝对值 `< 0.03 mm/cm`。

如果只达到 MVP，则至少需要 12 个样本、4 个区域、2 个袋口区域，台面误差 median `< 1.5 mm`、P95 `< 3.0 mm`。MVP 可用于调试，不建议作为正式交付结果。

## 11. 常见失败与处理

- **结果整体旋转 180°**：先检查相机方向是否为 180°，不要修改投影公式；重新做联合校准和球心补偿。
- **提示 `frame_rotation_degrees` 不兼容**：加载的是旧方向下的文件，重新校准，不要手工改 JSON。
- **提示 `distortion_fingerprint` 不兼容**：畸变文件或开关改变，联合校准和球心补偿都要重做。
- **提示 `projection_fingerprint` 不兼容**：平面联合校准已变化，球心补偿必须重做。
- **中心准确、边缘漂移**：增加边缘与袋口图案清晰度，检查畸变标定和台面轮廓，重新联合校准。
- **一侧准确、另一侧误差大**：检查投影焦平面、桌面缩放、台面四边形和留一图案 P95。
- **球心抖动或偏向高光**：固定曝光和白平衡，降低高光，改善分割掩膜，确保实际球直径配置正确。
- **投影圆看起来被拉伸**：这是视角与投射方向造成的正常各向异性；系统现在按局部椭圆投影，不应强制画成等半径圆。
- **球面上的光斑仍有偏差**：当前校准目标是“台面上的真实球心/球占位轮廓”，不是任意球面光斑。若需要把图案精确贴到球面，还需单独建立球面投影模型，不能用二维台面映射冒充。

## 12. 何时必须全部重做

出现以下任一情况，按本手册从第 3 步重新执行，并重新采集独立 Holdout：

- 相机、镜头或投影仪被移动；
- 相机方向、分辨率、焦距、对焦或畸变开关改变；
- 投影分辨率、屏幕缩放或投影焦点改变；
- 台面几何文件或球直径改变；
- 球检测模型改变；
- 联合校准文件被替换。
