# 相机坐标与投影方向

## 现场结论

新工业相机的安装方向与投影仪相差 `180°`。这个差异属于相机输入方向，应在采集边界归一化；投影仪的小角度歪斜属于投影细调，不应与 `180°` 混成一个输出旋转。

```text
工业相机原始帧
  → 安装方向归一化（当前：顺时针 180°）
  → 畸变校正（按总开关）
  → 检测、inline / outline / pocket、联合校准、球心补偿
  → 唯一投影仪像素坐标系
  → 投影细调（当前颗星公式 Rotation：-1.7°）
```

校准图样和运行 overlay 现在共用同一投影坐标域，不再分别旋转。这样同一个投影像素在校准和运行阶段始终落到同一物理位置。

## GUI 设置

1. 打开“设置 → 相机采集”。
2. 将“工业相机安装方向”设为“顺时针 180°”。
3. 投影输出页不再包含“校准画面旋转”或“运行输出旋转”。
4. 在“颗星公式 → Rotation”保留现场小角度值；当前为 `-1.7°`。
5. 保存后，相机方向与颗星公式参数会写入本机用户设置并在下次启动恢复。

旧用户设置中的 `projection_calibration_rotation_degrees` 和 `projection_output_rotation_degrees` 会被安全忽略；重新保存设置后不会再写出这两个字段。

## 标注旋转

Labelme 标注点的 `180°` 变换为：

```text
x' = imageWidth  - 1 - x
y' = imageHeight - 1 - y
```

仓库提供 `scripts/rotate_labelme_180.py` 批量转换工具。工具不会修改 `imagePath` 指向的 JPG，只转换三个 JSON 中的线条、轮廓和袋口标注点，并创建 `.pre180.bak` 原始备份。

## 重新校准

- 相机旋转会改变相机像素坐标域，已有联合平面校准和球心补偿必须重新生成。
- 更换相机机身、镜头、焦距、安装高度或位置后，即便方向仍为 `180°`，也必须重新校准。
- 投影仪的小角度偏移继续用现有细调参数处理，不要再增加全画布 `180°` 输出旋转。
- 正式校准前，工作台应显示“相机 180° / raw（或 undistorted）；投影校准与运行共用同一坐标系”。
