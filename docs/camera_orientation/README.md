# 工业相机安装方向归一化

## 简介

系统现在会在图像进入球检测、台面几何、联合校准和投影计算之前，统一处理工业相机的物理安装方向。

方向处理位于独立模块 `bas/capture/orientation.py`，不引入相机外参，也不修改球坐标或投影坐标公式。当前现场的新相机相对旧相机旋转了 180°，因此本机的 `local_settings/user_settings.json` 已设置：

```json
"frame_rotation_degrees": 180
```

该角度表示把采集帧顺时针旋转多少度后，才能恢复为系统一直使用的标准视图。支持 `0`、`90`、`180`、`270`，默认值为 `0`。

## 使用方法

1. 启动程序：

   ```powershell
   .\Start_BAS.cmd
   ```

2. 在“设置 → 相机采集 → 相机安装方向归一化”中选择“顺时针 180°”。
3. 保存设置。方向变化属于采集管线配置，程序会按现有机制重启采集管线。
4. 查看实时画面，确认球桌左上、右下以及球的位置与旧相机视图一致。

也可以直接编辑 `local_settings/user_settings.json`，然后重启程序。

## 处理顺序

```text
相机/视频原始帧
  → 安装方向归一化
  → 镜头畸变矫正（启用时）
  → 球心精修与检测
  → 独立二维几何映射
  → 投影输出
```

必须先恢复图像方向，再执行畸变矫正。这样旧标定中的内参主点仍对应标准图像坐标，不会因为先矫正倒置图像而产生额外边缘误差。

## 标定注意事项

- 如果只是同一台相机绕光轴旋转了 180°，恢复标准方向后，旧投影映射可继续作为初始结果使用。
- 如果更换了相机机身、镜头、焦距、安装高度或位置，即使画面方向已经修复，也应重新完成相机内参、台面映射、投影标定和球心补偿采样。
- 播放旧的正向录像时，应临时选择 `0°`；播放新倒置相机录制的原始录像时使用 `180°`。
