# 相机坐标与投影输出方向

## 简介

现场已经绘制好的 `inline`、`outline` 和 `pocket` 都属于相机像素坐标域。因此，更换后相机与投影结果相差 180° 时，不应旋转采集画面，否则已有几何标注会整体失效。

当前实现保持相机帧不变，并只在投影窗口的最终显示边界处理方向：

```text
相机原始帧（0°）
  → 畸变校正（按设置）
  → 检测、inline、outline、pocket
  → 独立二维几何与球心补偿
  → 逻辑投影帧
  → 校准模式：校准画面旋转角
  → 运行模式：运行输出旋转角
```

这两个投影角相互独立。运行输出的 180° 不会写回或覆盖校准画面方向，也不会覆盖“星图公式”中已有的细调旋转角。

## GUI 设置

在“设置 → 投影输出”中设置：

- “校准画面旋转”：联合校准图样、球心补偿目标和校准结果检查所使用的方向；当前现场保持 `0°`。
- “运行输出旋转”：正常路线、提示、动画和实时 overlay 的最终方向；当前现场设为“顺时针 180°”。

在“设置 → 相机采集”中，将“相机安装方向归一化”保持为“不旋转”。该选项只为没有既有像素标注的其他部署保留；当前现场不要用它修正投影方向。

保存设置后，三项角度都会写入本机用户设置并在下次启动时恢复。当前现场值为：

```json
{
  "frame_rotation_degrees": 0,
  "projection_calibration_rotation_degrees": 0,
  "projection_output_rotation_degrees": 180
}
```

## 校准注意事项

- 改变“校准画面旋转”会改变投影校准坐标域，现有联合校准和球心补偿会被判定为不兼容，需要重新完成两步校准。
- 只改变“运行输出旋转”不会改变相机、台面或球心补偿模型，也不会要求重画 `inline`、`outline`、`pocket`。
- 更换相机机身、镜头、焦距、安装高度或位置后，即使保持相机画面不旋转，也应重新完成联合校准和球心补偿。
- 正式校准前先在工作台确认状态栏显示“相机 0° / 投影校准 0° / 输出 180°”。
