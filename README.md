# BAS 本地说明

## 简介

这是一个台球辅助系统，包含实时视觉识别、球跟踪、状态机、进洞路线规划、前端 UI 预览和投影端路线显示。

这次调整后，进洞路线会复用同一套几何计算逻辑，同时用于：

- 投影端实时 overlay
- 前端 UI 实时预览画线

这样可以减少两套逻辑漂移，方便后续排查“投影有线、UI 没线”或“两边线型不一致”的问题。

## 如何使用

1. 安装依赖

```powershell
python -m pip install -r requirements.txt
```

2. 启动程序

```powershell
python -m bas
```

3. 在主界面中完成以下操作

- 点击“初始化图形图像模块”
- 点击“开始采集”
- 点击“开始投影”可在投影端显示路线
- 前端 UI 左侧实时预览会同步显示当前进洞路线

## 说明

- 规则模式和自由模式的路线都会进入前端 UI 预览绘制。
- 若现场没有看到路线，优先检查当前是否有 `best` 候选或 `free_route`。
- 日志、视频、模型、大文件应保持在 `.gitignore` 中，避免提交本地运行产物。
