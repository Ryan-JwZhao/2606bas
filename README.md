# BAS 本地说明

## 简介

这是一个台球辅助系统，包含实时采集、识别、跟踪、状态机、路线规划、前端预览与投影显示。

这次重点修复了几何线文件的热替换问题，涉及以下三个配置文件：

- `outline.json`
- `inline.json`
- `pocket.json`

现在程序会在运行过程中自动检查这些文件的路径与文件状态变化。即使路径不变，只是直接覆盖同名 JSON 内容，也会自动重新加载，不再继续使用启动时缓存的旧画线。

## 如何使用

1. 安装依赖

```powershell
python -m pip install -r requirements.txt
```

2. 启动程序

```powershell
python -m bas
```

3. 在界面中完成以下操作

- 打开“设置”，配置 `outline.json`、`inline.json`、`pocket.json`
- 点击“开始采集”
- 如需投影，再点击“开始投影”

## 热替换说明

- 修改几何文件路径后，设置保存会应用新的路径
- 不修改路径、只替换 JSON 文件内容时，采集运行中也会自动热重载
- 前端几何参考线预览读取的是运行时最新几何，不再固定使用旧缓存

## 排查建议

- 如果画线没有出现，先确认设置里的三个几何文件路径是否有效
- 如果路径有效但线型不对，检查对应 JSON 的 `label` 是否包含 `outline`、`inline`、`pocket`
- 本地日志、回放、模型、大文件与临时目录应保持在 `.gitignore` 中，避免提交运行产物
